What the server does

The EVW and local search stay on the client. The server receives the complete information needed for each request and retains no user corpus.

Conversational analysis

The server first tests the exact whole-corpus payload against the selected whole-corpus model budget. If it fits, one call answers it. Otherwise the server deterministically packs windows, extracts evidence, reduces only when necessary, and synthesizes the answer.

Embeddings

The client submits complete text workloads. The server batches and encodes them, streams visible progress and vectors back, and never opens the EVW. The client stores vectors and performs local similarity lookup.

What this number means

The displayed target is the maximum complete serialized input for one evidence-extraction call: hard input ceiling × utilization percentage. The deterministic planner chooses the fewest windows that fit, then balances the corpus between them, so actual windows are normally smaller than this maximum.
