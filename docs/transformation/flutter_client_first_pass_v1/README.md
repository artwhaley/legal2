# Flutter Client First Pass V1

This folder is the authoritative execution packet for turning the existing
Flutter transcript viewer into the first functional five-page client shell.
It does not redesign the server or the EVW.

Read every file completely in this order before editing:

1. `00_mission_scope_and_invariants.md`
2. `01_current_state_and_target_architecture.md`
3. `02_page_and_interaction_contracts.md`
4. `03_search_and_server_workflows.md`
5. `04_evidence_and_print_contracts.md`
6. `05_file_map_and_guardrails.md`
7. `06_ticket_stack.md`
8. `07_acceptance_gates.md`
9. `08_executor_protocol.md`
10. `kickoff_prompt.md`

`06_ticket_stack.md` is the implementation order. Files 00-05 contain binding
product and architecture decisions. Files 07-08 define proof and execution
discipline.

Maintain `execution_log.md` after every ticket. Create `closeout_report.md`
when complete. The copy/paste executor entry point is `kickoff_prompt.md`.
